# TASK-014 — Footer

## Objective
Build a minimal footer with navigation, contact links, and project identity.

## Acceptance Criteria
- [ ] Use `<footer>` landmark.
- [ ] Three-column layout on desktop, stacked on mobile:
  - **Product:** Home, Features, Architecture, Research, Stack
  - **Resources:** Documentation, GitHub, Demo video
  - **Connect:** Contact / email, Twitter/X (optional)
- [ ] Bottom row:
  - Left: `© 2026 DAMS — Defensive Agentic Memory System`
  - Right: `Built by studying open-source codebase-intelligence projects and extending them into practical AI tooling.`
- [ ] Include a subtle top border (`rgba(255,255,255,0.06)`).
- [ ] All links are keyboard-focusable and have visible focus states.
- [ ] Respect color contrast requirements.

## Notes
- Keep the footer minimal; it should not compete with the CTA section.
