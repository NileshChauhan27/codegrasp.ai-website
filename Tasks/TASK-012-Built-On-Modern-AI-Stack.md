# TASK-012 — Built on Modern AI Stack

## Objective
Create a logo grid section showing the technologies that power DAMS.

## Acceptance Criteria
- [ ] Section anchored to `#stack`.
- [ ] Heading: `Built on a modern AI stack.`
- [ ] Subheading: `Python, React, FastAPI, Ollama, Chunkhound, Graphify, DuckDB, Typer, GritQL, ragas, MCP, Obsidian.`
- [ ] Responsive grid of logo items:
  - 6 columns desktop, 4 tablet, 3 mobile.
  - Each logo is monochrome SVG, low opacity by default, full white on hover.
  - Tooltip on hover showing the technology name.
- [ ] Scroll reveal: logos fade in with stagger (50 ms between items).
- [ ] Each logo is focusable with a tooltip visible on focus.
- [ ] All logos must be local files in `public/logos/` (no external dependencies).

## Notes
- Keep the grid visually calm; this is a credibility section, not a sales pitch.
