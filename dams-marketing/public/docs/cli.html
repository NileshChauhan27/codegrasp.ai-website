CLI Reference

The dams CLI orchestrates the full lifecycle: init, capture, compile, verify, discover, and automate.

Project lifecycle

CommandDescription
dams new <name> --lang python --from-prd prd.mdCreate project, atomize PRD, init DAMS
dams initInitialize DAMS in an existing project (prompts for steering file name)
dams atomize <prd> --clearAI PRD decomposition (tasks + schema design)
dams recompileCompile wiki → steering file with freshness score
dams end "notes"Log session, regenerate steering file

Knowledge capture

CommandDescription
dams decide "Title" --files X,Y --why "..."Create a decision (ADR)
dams contract "Rule" --files X --severity criticalAdd a safety contract
dams trap "Cause" --fix "..." --file X --test pathCreate a regression trap
dams issue "Desc" --severity highLog an active issue
dams next "Task" --ref TASK-IDSet next priority (warms cache)

Task management

CommandDescription
dams tasks [--status pending] [--priority high]Show task tree, filterable
dams task <id>Full task details
dams task-execute <id> --copyExtract/copy agent execution prompt
dams task-done <id>Mark complete (or auto from commit)
dams task-generate "Feature"LLM-generate a new task
dams import-tasks <file.json>Offline import tasks from Web UI JSON
dams statusOne-glance project progress

Verification

CommandDescription
dams checkSafety gate against tracked files (pre-commit)
dams check --fixAuto-heal structural violations via GritQL
dams doctorDrift detection (orphans, staleness, contradictions)
dams dsl-validate|dsl-compile <file>Validate/compile Safety DSL → GritQL

Discovery

CommandDescription

dams callers <file>Who imports/calls this file?
dams graphify [build|--query|--explain]Knowledge graph operations
